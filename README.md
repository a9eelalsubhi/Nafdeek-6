# نفديك بدمائنا — النسخة السادسة

نسخة الموقع المستقلة والجاهزة للاستضافة على GitHub Pages.
المحتوى والتصميم والتفاعلات مطابقة للنسخة المنشورة رقم ٢٨.

## الملفات المطلوبة

- `index.html`: العرض كاملًا، ويحتوي على التنسيقات والتفاعلات ونص المتحدث المضمن.
- `assets/`: الصور والباركود والرسومات التي يستخدمها العرض. ارفع المجلد كاملًا دون تغيير أسماء ملفاته.
- `.nojekyll`: يجعل GitHub ينشر الملفات كما هي.

لا تحتاج تثبيت Node.js أو تشغيل عملية بناء.

## الرفع من صفحة المستودع

1. فك ضغط `Nafdeek-6-GitHub-Pages.zip` على جهازك.
2. افتح المستودع: https://github.com/a9eelalsubhi/Nafdeek-6
3. اضغط **Add file → Upload files**.
4. اسحب محتويات المجلد بعد فك الضغط: `index.html` و`assets` و`.nojekyll` و`README.md`.
   يجب أن يظهر `index.html` مباشرة بجانب `README.md` في الصفحة الرئيسية للمستودع.
   لا ترفع ملف ZIP نفسه، ولا ترفع المجلد الخارجي فوق الملفات.
5. اكتب وصفًا مثل `Add Nafdeek presentation website` ثم اضغط **Commit changes** لحفظها في `main`.
   إذا ظهر خيار **Propose changes**، أكمل طلب الدمج وادمجه في `main`.
6. افتح **Settings → Pages**.
7. في **Source** اختر **Deploy from a branch**، ثم اختر **main** و**/(root)**، واضغط **Save**.
8. انتظر اكتمال النشر، ثم اضغط **Visit site** من صفحة Pages. قد يستغرق النشر حتى ١٠ دقائق.

الرابط المتوقع بعد تفعيل النشر:
https://a9eelalsubhi.github.io/Nafdeek-6/

هذا رابط تحت اسم حسابك. إذا أردت رابطًا دون اسم المستودع، يمكن استخدام مستودع باسم
`a9eelalsubhi.github.io`. ويمكن لاحقًا ربط نطاق خاص تملكه.

## تجربة الموقع وتحديثه

يمكن فتح `index.html` محليًا لتجربة العرض، مع بقاء مجلد `assets` بجانبه.
الانتقال بالسابق والتالي أو أسهم لوحة المفاتيح وPageUp وPageDown، وملء الشاشة من الزر الموجود في العرض.
للتحديث، عدّل الملفات في نسختك ثم ارفع الملفات المعدلة إلى `main` بالطريقة نفسها. سيعاد نشر الموقع تلقائيًا.

حُفظت النصوص والرسومات الحالية دون تعديل، بما فيها باركود التسجيل ليومي ١٩ و٢٠ أكتوبر.
الباركود يفتح النموذج الخارجي نفسه، وتغيير الاستضافة لا يغير هذا النموذج أو إعداداته.
الخط العربي يُحمَّل من Google Fonts عند توفر الإنترنت.
